## 概要

Blue Whale API は完全なRESTful APIインターフェースを提供し、**AIモデルインターフェース**と**管理インターフェース**の2つの主要なカテゴリに分けられます。これらのインターフェースを通じて、AI機能の呼び出しとシステム管理機能を実現できます。

<Callout title="オンラインデバッグ">
  以下にアクセスして [Apifox 操練場](https://apifox.bluewhale.ai/) APIインターフェースをオンラインでテストおよびデバッグするか、以下のAPIドキュメントを参照してください。
</Callout>
