# 模型列表

当前对外开放的视频生成模型：**seedance-2.0**。

## seedance-2.0-whitelist

| 参数 | 可选值 | 默认值 |
| --- | --- | --- |
| 分辨率 `metadata.resolution` | 480p / 720p / 1080p / 4k | 720p |
| 画面比例 `metadata.ratio` | 16:9 / 4:3 / 1:1 / 3:4 / 9:16 / 21:9 / adaptive | 16:9 |
| 视频时长 `duration` | 1–30 秒（官方能力 4–15） | 5 秒 |
| 生成方式 | 文生视频 · 图生视频（首帧 `images`） | 文生视频 |
| 音频 | `metadata.generate_audio`（默认开启） | true |
| 输出格式 | MP4 ⚠️ 以官方确认为准 | MP4 |

各参数的请求写法见[提交任务](./video/submit)。
