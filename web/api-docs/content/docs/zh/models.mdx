# 模型列表

当前对外开放的视频生成模型：**seedance-2.0**。

## seedance-2.0-whitelist

| 参数 | 可选值 | 默认值 |
| --- | --- | --- |
| 分辨率 `size` | 480p / 720p / 1080p | 720p |
| 画面比例 `aspect_ratio` | 16:9 / 9:16 / 1:1 | 16:9 |
| 视频时长 `duration` | 4–15 秒，步长 1 秒 | 5 秒 |
| 生成方式 | 文生视频 · 图生视频 · 首尾帧 · 参考图 | 文生视频 |
| 音频 | 支持（随视频生成） | — |
| 输出格式 | MP4 ⚠️ 以官方确认为准 | MP4 |

各参数的请求写法见[提交任务](./video/submit)。
