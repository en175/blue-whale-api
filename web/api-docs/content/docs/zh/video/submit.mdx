---
title: 提交任务
description: 提交视频生成任务，获取 task_id
---

**POST** `/v1/video/generations`

提交一次视频生成任务。接口立即返回 `task_id`，生成异步进行，通过[查询任务](./query)跟进进度。

## 请求头

| 名称 | 必填 | 说明 |
| --- | --- | --- |
| `Authorization` | 是 | `Bearer sk-xxx`（控制台创建的 API Key，见[鉴权](../authentication)） |
| `Content-Type` | 是 | `application/json` |

## 请求参数

| 字段 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `prompt` | string | 是 | — | 提示词（视频内容描述） |
| `model` | string | 是 | — | 模型标识，可选值见[模型列表](../models) |
| `images` | string[] | 否 | — | 图生视频：首帧/参考图 URL 数组（公网可访问） |
| `seconds` | string | 否 | `5` | 视频时长（秒） |
| `metadata.resolution` | string | 否 | `720p` | 分辨率：`480p` / `720p` / `1080p` / `4k` |
| `metadata.ratio` | string | 否 | `16:9` | 画面比例：`16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `21:9` / `adaptive` |
| `metadata.generate_audio` | bool | 否 | `true` | 是否生成音频 |
| `metadata.frames` | int | 否 | — | 帧数 |
| `metadata.seed` | int | 否 | — | 随机种子（固定结果） |
| `metadata.camera_fixed` | bool | 否 | `false` | 固定机位 |
| `metadata.watermark` | bool | 否 | `false` | 水印 |
| `metadata.service_tier` | string | 否 | — | 服务档位（如 `fast`） |
| `metadata.return_last_frame` | bool | 否 | `false` | 返回尾帧 |
| `metadata.callback_url` | string | 否 | — | 回调地址（Webhook） |

## 示例

### 文生视频

```bash
BASE_URL="https://api.bluewhale.ai"   # 占位示意，正式域名以官方公告为准

curl "$BASE_URL/v1/video/generations" \
  -H "Authorization: Bearer sk-YOUR-KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-0-260128",
    "prompt": "蓝鲸跃出海面，慢镜头，电影质感",
    "seconds": "5",
    "metadata": {
      "resolution": "720p",
      "ratio": "16:9",
      "generate_audio": true
    }
  }'
```

### 图生视频（首帧）

```bash
curl "$BASE_URL/v1/video/generations" \
  -H "Authorization: Bearer sk-YOUR-KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-0-260128",
    "prompt": "镜头缓慢推进，画面中的杯子轻轻晃动",
    "images": ["https://example.com/first-frame.jpg"],
    "seconds": "5",
    "metadata": {
      "resolution": "720p"
    }
  }'
```

## 响应

```json
{
  "code": "success",
  "message": "",
  "data": {
    "task_id": "task_9f3a2b7c",
    "status": "QUEUED"
  }
}
```

记下 `data.task_id`，用它[查询任务](./query)与[下载视频](./download)。
