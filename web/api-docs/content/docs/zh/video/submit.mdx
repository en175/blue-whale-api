**POST** `/v1/video/generations`

提交一次视频生成任务。接口立即返回 `task_id`，生成异步进行，通过[查询任务](./query)跟进进度。

## 请求头

| 名称 | 必填 | 说明 |
| --- | --- | --- |
| `Authorization` | 是 | `Bearer sk-xxx`（控制台创建的 API Key，见[鉴权](../authentication)） |
| `Content-Type` | 是 | `application/json` |

## 请求参数

接口参数分两类:

- **顶层参数**(外部参数):由网关统一解析,所有通道共用,字段名固定。
- **`metadata` 参数**:一个透传对象,承载上游/模型特有的扩展能力(分辨率、画面比例、多模态参考素材、水印等)。网关不解析其内部结构,**下表列出的 `metadata` 字段会透传给上游**——因此官网(火山方舟 Seedance)的 `content` / `ratio` / `generate_audio` / `watermark` 等参数,在本接口中统一放进 `metadata`(时长例外:正数时长优先用顶层 `seconds`,特殊值 `-1` 只能用 `metadata.duration`,见「时长怎么传」)。

### 顶层参数

| 字段 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `prompt` | string | 是 | — | 提示词（视频内容描述） |
| `model` | string | 是 | — | 模型标识，可选值见[模型列表](../models) |
| `images` | string[] | 否 | — | 图生视频：首帧 URL 数组（公网可访问；参考图请用 `metadata.content` + `role:"reference_image"`） |
| `seconds` | string | 否 | `5` | 视频时长（秒），对应官网 `duration`。**只接受正整数**；`-1`（跟随输入视频）必须改用 `metadata.duration`，见「时长怎么传」 |

### metadata 参数

| 字段 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `duration` | int | 否 | — | 视频时长（秒）。正数时长请优先用顶层 `seconds`；**`-1`（跟随输入视频）只能在这里传**——顶层 `seconds` 传不了负数。见「时长怎么传」 |
| `resolution` | string | 否 | `720p` | 分辨率：`480p` / `720p` / `1080p` / `4k` |
| `ratio` | string | 否 | `16:9` | 画面比例：`16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `21:9` / `adaptive` |
| `generate_audio` | bool | 否 | `true` | 是否生成音频（使用参考音频/背景音乐时需为 `true`） |
| `content` | array | 否 | — | 多模态参考素材数组（参考图 / 参考视频 / 参考音频），元素形如 `{type, image_url\|video_url\|audio_url, role}`；参考视频：`type:"video_url"` + `role:"reference_video"`（公网 URL，最多 3 段、单段 2–15s） |
| `content[].audio_url` | object | 否 | — | 参考音频（背景音乐/音效）：`{type:"audio_url", audio_url:{url}, role:"reference_audio"}`；公网 URL，最多 3 段；**不能单独作为参考**——须至少搭配 1 张参考图或 1 段参考视频 |
| `omni_reference_task_type` | string | 否 | `auto` | 任务类型引导（**仅 Seedance 2.5**）：`auto` / `reference`（参考生视频）/ `edit`（视频编辑）/ `extend`（视频延长）。显式指定可把参数约束校验**前置到提交时**（否则任务启动后异步报错）。详见下方「V2V 任务类型与参数规范」 |
| `frames` | int | 否 | — | 帧数 |
| `seed` | int | 否 | — | 随机种子（固定结果） |
| `camera_fixed` | bool | 否 | `false` | 固定机位 |
| `watermark` | bool | 否 | `false` | 水印 |
| `service_tier` | string | 否 | — | 服务档位（如 `fast`） |
| `return_last_frame` | bool | 否 | `false` | 返回尾帧 |
| `callback_url` | string | 否 | — | 回调地址（Webhook） |

各模型支持的 `metadata` 选项见[模型列表](../models)。

### 参数放置规则

- **必填/公共**：`prompt` / `model` / `seconds` → 放**顶层**
- **扩展能力**：`resolution` / `ratio` / `generate_audio` / `content` / `watermark` 等 → 放 **`metadata`**
- **首帧/首尾帧**：顶层 `images`（单首帧，最简）或 `metadata.content` 里 `role:"first_frame"` / `"last_frame"`
- **参考素材**（参考图 / 参考视频 / 参考音频）：统一走 `metadata.content` + `role:"reference_*"`；不要与顶层 `images` 混用（混用时 `metadata.content` 会覆盖 `images`）
- **时长**：见下方「时长怎么传」——正数放顶层 `seconds`，`-1` 只能用 `metadata.duration`

### 时长怎么传

`seconds` 与 `duration` 分属不同层级，在 Seedance 2.5 渠道上行为**不对称**，传错会静默失效或被 400 拒绝：

| 写法 | 是否生效 | 说明 |
| --- | --- | --- |
| 顶层 `seconds: "5"` | ✅ | 常规写法。**只接受正整数**（1~3600），网关转成上游 `duration` 下发 |
| 顶层 `duration: 5` | ❌ | 会被校验，但**不转发**给上游（静默丢弃），勿用 |
| `metadata.duration: 5` | ✅ | 直接进上游请求体 |

**优先级**：顶层 `seconds` 解析为正数时，覆盖 `metadata.duration`；为 `0` / 空 / 非数字时不覆盖。

**`-1`（跟随输入视频）只能走 `metadata.duration`**：顶层 `seconds` 与顶层 `duration` 都要过 1~3600 校验，传 `-1` 会直接返回 400 `invalid_seconds`。

```json
{
  "model": "doubao-seedance-2-5-260628",
  "prompt": "把画面里的奶油换成红色",
  "metadata": {
    "duration": -1,
    "ratio": "adaptive",
    "content": [{"type": "video_url", "video_url": {"url": "https://your-host/clip.mp4"}, "role": "reference_video"}]
  }
}
```

> 视频编辑任务的 `duration` 必须为 `-1`，所以编辑场景**不要**传顶层 `seconds`——它会覆盖 `metadata.duration`。详见下方「V2V 任务类型与参数规范」。

## V2V 任务类型与参数规范（重要说明）

> **⚠️ 2.5 视频编辑类 prompt 的时长必须为 `-1`，且只能通过 `metadata.duration` 传**（顶层 `seconds` 无法表达负数，网关会直接 400），否则任务 `FAILURE`。

Seedance 2.5（`doubao-seedance-2-5-260628`）会根据 prompt 语义**智能识别任务类型**：当 prompt 是对**视频内容的修改指令**（如"奶油换成红色"）时，被识别为**视频编辑任务**，而非参考视频生成。视频编辑任务的输出是"基于模型选定的输入视频"改造而来，**输出时长与比例必须跟随输入视频，不能由用户指定**。

- **时长必须为 `-1`**（表示跟随输入视频），只能写成 `metadata.duration: -1`；输入视频时长需在 **4~30s** 内。
- 若指定了具体时长（顶层 `seconds: "5"`，或 `metadata.duration: 5`），违反该约束 → 上游参数校验失败 → 任务 `FAILURE`。
- **2.0 / fast / mini 不受此限制**：始终按视频生成处理，接受具体 `seconds`（如 `5` / `10`）。

| 场景 | 任务类型 | 时长 | `ratio` | 输入视频 | 适用模型 |
| --- | --- | --- | --- | --- | --- |
| 参考视频引导生成 | 视频生成 | 顶层 `seconds`（`"5"` / `"10"`） | 具体值（`16:9` 等） | 可选 | 2.0 / fast / mini |
| 修改视频内容 | 视频编辑 | `metadata.duration: -1` | 跟随输入视频 | 必填，4~30s | 2.5（智能识别） |

依据火山方舟文档：2.5 编辑任务的 `duration` 只支持 `-1`；2.0 / fast / mini 不受限，始终按视频生成处理，接受具体时长（如 `5` / `10`）。

### 显式引导任务类型（仅 2.5）

不想依赖智能识别时，用 `metadata.omni_reference_task_type` 显式声明，可把参数约束校验**前置到提交时**——不符合立即返回 400，不会先建任务再异步失败：

| 取值 | 任务类型 | 附加约束 |
| --- | --- | --- |
| `auto` | 模型自动判定（默认，等同不传） | — |
| `reference` | 参考生视频 | 时长（`seconds` 或 `metadata.duration`）/ `ratio` 无特殊限制 |
| `edit` | 视频编辑 | `ratio` 须 `adaptive`、时长须 `metadata.duration: -1`；参考视频 4~30s |
| `extend` | 视频延长 | `ratio` 须 `adaptive`；`content` 须含参考视频 |

**⚠️ 显式指定不保证按该类型生成**：上游仍会结合 prompt 语义判定，二者不一致时任务仍会异步失败。请按上表对应的提示词写法组织 prompt。非字符串取值会被网关拒绝（400 `invalid_omni_reference_task_type`）。

## 示例

### 文生视频

```bash
BASE_URL="https://yunjizi.cn"   # 国内；国外用 https://api.yunjizi.cn

curl "$BASE_URL/v1/video/generations" \
  -H "Authorization: Bearer sk-YOUR-KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-0-260128",
    "prompt": "蓝鲸跃出海面，慢镜头，电影质感",
    "seconds": "5",
    "metadata": {
      "resolution": "720p",
      "ratio": "16:9",
      "generate_audio": true
    }
  }'
```

### 图生视频（首帧）

```bash
curl "$BASE_URL/v1/video/generations" \
  -H "Authorization: Bearer sk-YOUR-KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-0-260128",
    "prompt": "镜头缓慢推进，画面中的杯子轻轻晃动",
    "images": ["https://example.com/first-frame.jpg"],
    "seconds": "5",
    "metadata": {
      "resolution": "720p"
    }
  }'
```

### 参考生视频（多模态）

参考图 / 参考视频 / 参考音频可任意组合（音频不能单独作为参考，须至少搭配 1 张参考图或 1 段参考视频），全部放在 `metadata.content` 中；对应官网 Seedance 的 `content` 数组（`role` 取值：`reference_image` / `reference_video` / `reference_audio`）。提示词里的「首帧/尾帧」是视频内容的叙述，素材角色由 `role` 决定，与放置规则中的 `first_frame` / `last_frame` 控制无关。

```bash
curl "$BASE_URL/v1/video/generations" \
  -H "Authorization: Bearer sk-YOUR-KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-0-260128",
    "prompt": "全程使用视频1的第一视角构图，全程使用音频1作为背景音乐。第一人称视角果茶宣传广告，seedance牌「苹苹安安」苹果果茶限定款；首帧为图片1，你的手摘下一颗带晨露的阿克苏红苹果，轻脆的苹果碰撞声；2-4 秒：快速切镜，你的手将苹果块投入雪克杯，加入冰块与茶底，用力摇晃，冰块碰撞声与摇晃声卡点轻快鼓点，背景音：「鲜切现摇」；4-6 秒：第一人称成品特写，分层果茶倒入透明杯，你的手轻挤奶盖在顶部铺展，在杯身贴上粉红包标，镜头拉近看奶盖与果茶的分层纹理；6-8 秒：第一人称手持举杯，你将图片2中的果茶举到镜头前（模拟递到观众面前的视角），杯身标签清晰可见，背景音「来一口鲜爽」，尾帧定格为图片2。背景声音统一为女生音色。",
    "seconds": "11",
    "metadata": {
      "ratio": "16:9",
      "generate_audio": true,
      "watermark": false,
      "content": [
        {"type": "image_url", "image_url": {"url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/r2v_tea_pic1.jpg"}, "role": "reference_image"},
        {"type": "image_url", "image_url": {"url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/r2v_tea_pic2.jpg"}, "role": "reference_image"},
        {"type": "video_url", "video_url": {"url": "https://ark-project.tos-cn-beijing.volces.com/doc_video/r2v_tea_video1.mp4"}, "role": "reference_video"},
        {"type": "audio_url", "audio_url": {"url": "https://ark-project.tos-cn-beijing.volces.com/doc_audio/r2v_tea_audio1.mp3"}, "role": "reference_audio"}
      ]
    }
  }'
```

### 音频参考生视频

参考音频（`role:"reference_audio"`）作为背景音乐/音效，提示词用「音频1」指代；**音频不能单独作为参考**，须至少搭配 1 张参考图或 1 段参考视频，`generate_audio` 保持 `true`。

```bash
curl "$BASE_URL/v1/video/generations" \
  -H "Authorization: Bearer sk-YOUR-KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-0-260128",
    "prompt": "以图片1为画面参考、音频1为背景音乐：海边日出，浪花轻拍沙滩，镜头缓缓推进到晨光中的灯塔，氛围宁静治愈。",
    "seconds": "5",
    "metadata": {
      "resolution": "720p",
      "ratio": "16:9",
      "generate_audio": true,
      "content": [
        {"type": "image_url", "image_url": {"url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/r2v_tea_pic1.jpg"}, "role": "reference_image"},
        {"type": "audio_url", "audio_url": {"url": "https://ark-project.tos-cn-beijing.volces.com/doc_audio/r2v_tea_audio1.mp3"}, "role": "reference_audio"}
      ]
    }
  }'
```

### 完整参数（首帧 + 可选 metadata 字段）

> 说明：本示例以顶层 `images` 作首帧，因此不含 `metadata.content`——多模态参考与首帧互斥（见参数放置规则），参考生视频请用上方示例。

```bash
curl "$BASE_URL/v1/video/generations" \
  -H "Authorization: Bearer sk-YOUR-KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-0-260128",
    "prompt": "蓝鲸跃出海面，慢镜头，电影质感",
    "images": ["https://example.com/first-frame.png"],
    "seconds": "5",
    "metadata": {
      "resolution": "720p",
      "ratio": "16:9",
      "generate_audio": true,
      "frames": 30,
      "seed": 42,
      "camera_fixed": false,
      "watermark": false,
      "service_tier": "fast",
      "return_last_frame": false,
      "callback_url": "https://example.com/webhook"
    }
  }'
```

## 响应

接口返回 OpenAI 兼容的 video 对象，`id`（与 `task_id` 相同）即任务标识，`status` 为排队中：

```json
{
  "id": "task_9f3a2b7c",
  "task_id": "task_9f3a2b7c",
  "object": "video",
  "model": "doubao-seedance-2-0-260128",
  "status": "queued",
  "progress": 0,
  "created_at": 1786344639
}
```

记下 `id`（即 `task_id`），用它[查询任务](./query)与[下载视频](./download)。
