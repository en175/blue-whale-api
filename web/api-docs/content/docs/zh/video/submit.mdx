**POST** `/v1/video/generations`

提交一次视频生成任务。接口立即返回 `task_id`，生成异步进行，通过[查询任务](./query)跟进进度。

## 请求参数

| 字段 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `prompt` | string | 是 | — | 视频内容描述 |
| `model` | string | 是 | — | 固定传 `seedance-2.0-whitelist` |
| `duration` | integer | 否 | 5 | 视频时长（秒），1–30 |
| `images` | string[] | 否 | — | 图生视频：首帧图片 URL 列表（公网可访问） |
| `metadata` | object | 否 | — | 扩展参数，透传给上游（分辨率、画面比例、音频等，见[模型列表](../models)） |

## 示例

### 文生视频

```bash
BASE_URL="https://api.bluewhale.ai"   # 占位示意，正式域名以官方公告为准

curl "$BASE_URL/v1/video/generations" \
  -H "Authorization: Bearer sk-YOUR-KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2.0-whitelist",
    "prompt": "蓝鲸跃出海面，慢镜头，电影质感",
    "duration": 5,
    "metadata": {
      "resolution": "720p",
      "ratio": "16:9",
      "generate_audio": false
    }
  }'
```

### 图生视频（首帧）

```bash
curl "$BASE_URL/v1/video/generations" \
  -H "Authorization: Bearer sk-YOUR-KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2.0-whitelist",
    "prompt": "镜头缓慢推进，画面中的杯子轻轻晃动",
    "images": ["https://example.com/first-frame.jpg"],
    "duration": 5,
    "metadata": {
      "resolution": "720p"
    }
  }'
```

## 响应

```json
{
  "code": "success",
  "message": "",
  "data": {
    "task_id": "task_9f3a2b7c",
    "status": "QUEUED"
  }
}
```

记下 `data.task_id`，用它查询进度与下载结果。
