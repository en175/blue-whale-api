从注册到拿到第一条生成视频，全程约 5 分钟。

## 1. 获取 API Key

1. 注册并登录控制台
2. 进入「令牌」页面，创建一个新的 API Key（形如 `sk-xxxxxx`）
3. 妥善保存——Key 只在创建时完整展示一次

## 2. 提交生成任务

> **Base URL**：国内 `https://yunjizi.cn`；国外 `https://api.yunjizi.cn`。请按部署环境二选一，下文示例中的 `BASE_URL` 即对应域名。

```bash
BASE_URL="https://yunjizi.cn"   # 国内；国外用 https://api.yunjizi.cn

curl "$BASE_URL/v1/video/generations" \
  -H "Authorization: Bearer sk-YOUR-KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-0-260128",
    "prompt": "蓝鲸跃出海面，慢镜头，电影质感",
    "seconds": "5",
    "metadata": {
      "resolution": "720p",
      "ratio": "16:9",
      "generate_audio": true
    }
  }'
```

响应中的 `id`（即 `task_id`）就是这次任务的唯一标识：

```json
{
  "id": "task_9f3a2b7c",
  "task_id": "task_9f3a2b7c",
  "object": "video",
  "status": "queued"
}
```

## 3. 轮询任务状态

视频生成为异步任务，建议每 5–10 秒轮询一次：

```bash
curl "$BASE_URL/v1/video/generations/task_9f3a2b7c" \
  -H "Authorization: Bearer sk-YOUR-KEY"
```

当 `data.status` 变为 `SUCCESS` 时，生成完成。详见[查询任务](./video/query)。

## 4. 下载视频

```bash
curl "$BASE_URL/v1/videos/task_9f3a2b7c/content" \
  -H "Authorization: Bearer sk-YOUR-KEY" \
  -o result.mp4
```
