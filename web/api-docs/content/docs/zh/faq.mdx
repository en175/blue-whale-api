## 生成一条视频要多久？

通常几十秒到数分钟，取决于时长与分辨率参数。提交后通过轮询跟进进度，建议轮询间隔 5–10 秒。

## 支持哪些画面比例？

16:9（横屏）、9:16（竖屏）、1:1（方形），默认 16:9。

## 图生视频怎么传图？

请求体传 `image`（首帧图 URL）或 `images` 字段；首尾帧与参考图控制见[模型列表](./models)。

## 任务失败了怎么办？

查询接口返回 `status=FAILURE` 时，查看 `fail_reason` 字段定位原因；参数类问题修正后重新提交即可。

## 生成结果保留多久？

请及时下载保存，具体保留时长以官方确认为准。

## 有 Webhook 回调吗？

当前版本通过轮询获取结果，回调能力如有排期将另行公告。
