## BLUE WHALE API 文档

面向开发者的视频生成 API：一套 API Key、一套计费、一个 base_url，异步任务模式交付。当前开放模型为 **doubao-seedance-2-0-260128**，支持文生视频、图生视频、首尾帧与参考图控制、音频生成。

## 当前开放的端点

- `POST /v1/video/generations` — 提交视频生成任务
- `GET /v1/video/generations/{task_id}` — 查询任务状态
- `GET /v1/videos/{task_id}/content` — 下载生成的视频
