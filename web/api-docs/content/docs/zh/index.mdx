## BLUE WHALE API 文档

面向开发者的多模态生成 API：一套 API Key、一套计费、一个 base_url。当前开放三类能力——**文本模型**（支持 OpenAI Chat Completions、Anthropic Messages、OpenAI Responses 三种调用格式）、**图片模型**（图片生成与图片编辑）、**视频模型**（Doubao-Seedance 2.5 / 2.0 / 2.0-mini / 2.0-fast 系列，异步任务模式交付）。完整模型清单见[模型列表](./models)。

## 当前开放的端点

- `POST /v1/chat/completions` — 对话补全（OpenAI Chat Completions 格式）
- `POST /v1/messages` — 对话补全（Anthropic Messages 格式）
- `POST /v1/responses` — 对话补全（OpenAI Responses 格式）
- `POST /v1/images/generations` — 图片生成
- `POST /v1/images/edits` — 图片编辑
- `POST /v1/video/generations` — 提交视频生成任务
- `GET /v1/video/generations/{task_id}` — 查询任务状态
- `GET /v1/videos/{task_id}/content` — 下载生成的视频
