## Blue Whale API Integration Method

### Parameter Configuration

Provider Type: Types supported by Blue Whale API
API Key: Obtained from Blue Whale API
API Address: Blue Whale API Site Address

Please use your self-deployed Blue Whale API, or ensure that the service provider has a Blue Whale API service with legal upstream authorization and compliance obligations. Do not integrate API addresses or keys from unknown sources into a production environment.
