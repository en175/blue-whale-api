# Models

The video generation model currently open to the public: **seedance-2.0**.

## seedance-2.0-whitelist

| Parameter | Allowed Values | Default |
| --- | --- | --- |
| Resolution `metadata.resolution` | 480p / 720p / 1080p / 4k | 720p |
| Aspect ratio `metadata.ratio` | 16:9 / 4:3 / 1:1 / 3:4 / 9:16 / 21:9 / adaptive | 16:9 |
| Duration `duration` | 1–30 seconds (official capability: 4–15) | 5 seconds |
| Generation mode | Text-to-video · Image-to-video (first frame via `images`) | Text-to-video |
| Audio | `metadata.generate_audio` (enabled by default) | true |
| Output format | MP4 ⚠️ Subject to official confirmation | MP4 |

For request syntax of each parameter, see [Submit a Task](./video/submit).
