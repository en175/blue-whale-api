## BLUE WHALE API DOCS

A multimodal generation API for developers: one API key, one billing system, one base_url. Three capability families are currently open — **text models** (with OpenAI Chat Completions, Anthropic Messages and OpenAI Responses call formats), **image models** (image generation and image editing), and **video models** (the Doubao-Seedance 2.5 / 2.0 / 2.0-mini / 2.0-fast series, delivered in asynchronous task mode). See the [model list](./models) for the full catalog.

## Currently Open Endpoints

- `POST /v1/chat/completions` — Chat completions (OpenAI Chat Completions format)
- `POST /v1/messages` — Chat completions (Anthropic Messages format)
- `POST /v1/responses` — Chat completions (OpenAI Responses format)
- `POST /v1/images/generations` — Image generation
- `POST /v1/images/edits` — Image editing
- `POST /v1/video/generations` — Submit a video generation task
- `GET /v1/video/generations/{task_id}` — Query task status
- `GET /v1/videos/{task_id}/content` — Download the generated video
