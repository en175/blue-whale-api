## BLUE WHALE API DOCS

A video generation API for developers: one API key, one billing system, one base_url, delivered in asynchronous task mode. The currently open model is **seedance-2.0-whitelist**, supporting text-to-video, image-to-video, first/last-frame and reference-image control, and audio generation.

## Currently Open Endpoints

- `POST /v1/video/generations` — Submit a video generation task
- `GET /v1/video/generations/{task_id}` — Query task status
- `GET /v1/videos/{task_id}/content` — Download the generated video
