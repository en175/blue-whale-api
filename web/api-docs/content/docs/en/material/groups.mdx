title: Asset Groups

An asset group is the container for assets. Create a group first, then upload assets into it (see [Assets](../material/assets)). All four Actions below use the **CRUD envelope** response format.

> **Ark-compatible entry:** every Action on this page also works as `POST /?Action={Action}&Version=2024-01-01` (alias `/api/ark`). Request bodies and ownership checks are identical; only the URL shape and the error envelope differ — see the [endpoint comparison](../material/index#endpoints).

## GetAssetGroup — Get Asset Group Details

Query an asset group by `Id`. **Only groups owned by the current API key are accessible**; others return `404 NotFound`.

### Request

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `Id` | string | Yes | Asset group id (`group-...`) |

```bash
BASE_URL="https://yunjizi.cn"   # Domestic; overseas use https://api.yunjizi.cn

curl "$BASE_URL/api/material/GetAssetGroup" \
  -H "Authorization: Bearer sk-YOUR-KEY" \
  -H "Content-Type: application/json" \
  -d '{"Id":"group-xxx"}'
```

### Response

```json
{
  "ResponseMetadata": { "RequestId": "req_xxx", "Action": "GetAssetGroup", "Version": "2024-01-01", "Service": "ark", "Region": "cn-beijing" },
  "Result": { "Id": "group-xxx", "Name": "My Asset Group", "GroupType": "AIGC", "CreateTime": "2026-08-19T02:10:00Z", "UpdateTime": "2026-08-19T02:10:00Z" }
}
```

## CreateAssetGroup — Create Asset Group

### Request

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `Name` | string | Yes | Group name (≤255 chars, no `<`/`>`, otherwise `400 InvalidParameter`). **Prefer ASCII** — upstream may corrupt Chinese names into `�` |
| `Description` | string | No | Description |
| `GroupType` | string | Yes | Group type; currently only `AIGC` |

```bash
BASE_URL="https://yunjizi.cn"   # Domestic; overseas use https://api.yunjizi.cn

curl "$BASE_URL/api/material/CreateAssetGroup" \
  -H "Authorization: Bearer sk-YOUR-KEY" \
  -H "Content-Type: application/json" \
  -d '{"Name":"My Asset Group","Description":"test","GroupType":"AIGC"}'
```

### Response

```json
{
  "ResponseMetadata": { "RequestId": "req_xxx", "Action": "CreateAssetGroup", "Version": "2024-01-01", "Service": "ark", "Region": "cn-beijing" },
  "Result": { "Id": "group-xxx" }
}
```

## UpdateAssetGroup — Update Asset Group

> Both `Description` and `Name` can be updated; `Name` must be ≤255 chars and free of `<`/`>` (otherwise `400 InvalidParameter`). Groups not owned by you return `404 NotFound`.
>
> Note: renaming (`Name`) writes straight to upstream, but `ListAssetGroups` is served from the gateway's local ownership table, which is **not refreshed immediately** after a rename — it may still show the old name. Trust the `GetAssetGroup` (direct upstream) result.

### Request

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `Id` | string | Yes | Asset group id |
| `Description` | string | No | New description |
| `Name` | string | No | New name (≤255 chars, no `<`/`>`, otherwise 400 `InvalidParameter`) |

```bash
BASE_URL="https://yunjizi.cn"   # Domestic; overseas use https://api.yunjizi.cn

curl "$BASE_URL/api/material/UpdateAssetGroup" \
  -H "Authorization: Bearer sk-YOUR-KEY" \
  -H "Content-Type: application/json" \
  -d '{"Id":"group-xxx","Description":"New description"}'
```

### Response

```json
{
  "ResponseMetadata": { "RequestId": "req_xxx", "Action": "UpdateAssetGroup", "Version": "2024-01-01", "Service": "ark", "Region": "cn-beijing" },
  "Result": {}
}
```

## DeleteAssetGroup — Delete Asset Group

Deletes the group and **all assets within it**. Only groups owned by the current API key can be deleted; others return `404 NotFound` (gateway `groupOwnedByCurrentUser` check).

### Request

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `Id` | string | Yes | Asset group id |

```bash
BASE_URL="https://yunjizi.cn"   # Domestic; overseas use https://api.yunjizi.cn

curl "$BASE_URL/api/material/DeleteAssetGroup" \
  -H "Authorization: Bearer sk-YOUR-KEY" \
  -H "Content-Type: application/json" \
  -d '{"Id":"group-xxx"}'
```

### Response

```json
{
  "ResponseMetadata": { "RequestId": "req_xxx", "Action": "DeleteAssetGroup", "Version": "2024-01-01", "Service": "ark", "Region": "cn-beijing" },
  "Result": {}
}
```
