---
title: Submit a Task
description: Submit a video generation task and get a task_id
---

**POST** `/v1/video/generations`

Submit a video generation task. The endpoint returns a `task_id` immediately; generation runs asynchronously and progress is tracked via [Query a Task](./query).

## Request Headers

| Name | Required | Description |
| --- | --- | --- |
| `Authorization` | Yes | `Bearer sk-xxx` (API key created in the console; see [Authentication](../authentication)) |
| `Content-Type` | Yes | `application/json` |

## Request Parameters

| Field | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `prompt` | string | Yes | — | Description of the video content |
| `model` | string | Yes | — | Model identifier; available values see [Models](../models) |
| `images` | string[] | No | — | Image-to-video: first-frame/reference image URL array (publicly accessible) |
| `seconds` | string | No | `5` | Video duration in seconds |
| `metadata.resolution` | string | No | `720p` | Resolution: `480p` / `720p` / `1080p` / `4k` |
| `metadata.ratio` | string | No | `16:9` | Aspect ratio: `16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `21:9` / `adaptive` |
| `metadata.generate_audio` | bool | No | `true` | Whether to generate audio |
| `metadata.frames` | int | No | — | Number of frames |
| `metadata.seed` | int | No | — | Random seed (for deterministic results) |
| `metadata.camera_fixed` | bool | No | `false` | Fixed camera |
| `metadata.watermark` | bool | No | `false` | Watermark |
| `metadata.service_tier` | string | No | — | Service tier (e.g. `fast`) |
| `metadata.return_last_frame` | bool | No | `false` | Return the last frame |
| `metadata.callback_url` | string | No | — | Callback URL (webhook) |

## Examples

### Text-to-Video

```bash
BASE_URL="https://api.bluewhale.ai"   # Placeholder; the official domain will be announced separately

curl "$BASE_URL/v1/video/generations" \
  -H "Authorization: Bearer sk-YOUR-KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-0-260128",
    "prompt": "A blue whale leaping out of the ocean, slow motion, cinematic look",
    "seconds": "5",
    "metadata": {
      "resolution": "720p",
      "ratio": "16:9",
      "generate_audio": true
    }
  }'
```

### Image-to-Video (First Frame)

```bash
curl "$BASE_URL/v1/video/generations" \
  -H "Authorization: Bearer sk-YOUR-KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-0-260128",
    "prompt": "The camera slowly pushes in; the cup in the frame wobbles gently",
    "images": ["https://example.com/first-frame.jpg"],
    "seconds": "5",
    "metadata": {
      "resolution": "720p"
    }
  }'
```

### Full Parameters (All Optional Fields)

```bash
curl "$BASE_URL/v1/video/generations" \
  -H "Authorization: Bearer sk-YOUR-KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-0-260128",
    "prompt": "A blue whale leaping out of the ocean, slow motion, cinematic look",
    "images": ["https://example.com/first-frame.png"],
    "seconds": "5",
    "metadata": {
      "resolution": "720p",
      "ratio": "16:9",
      "generate_audio": true,
      "frames": 30,
      "seed": 42,
      "camera_fixed": false,
      "watermark": false,
      "service_tier": "fast",
      "return_last_frame": false,
      "callback_url": "https://example.com/webhook"
    }
  }'
```

## Response

The endpoint returns an OpenAI-compatible video object; `id` (same as `task_id`) is the task identifier and `status` is `queued`:

```json
{
  "id": "task_9f3a2b7c",
  "task_id": "task_9f3a2b7c",
  "object": "video",
  "model": "doubao-seedance-2-0-260128",
  "status": "queued",
  "progress": 0,
  "created_at": 1786344639
}
```

Note down `id` (i.e. `task_id`) — it is used to query progress and download the result.
