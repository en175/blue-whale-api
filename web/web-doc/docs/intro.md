# Blue Whale API 文档

Blue Whale AI 模型接口文档，兼容 OpenAI API 格式，覆盖聊天、补全、嵌入、重排序、审查、音频、实时语音、图像、视频、模型列表等能力。

## 接口分类

左侧导航「接口文档」下按**大类 > 格式**两层分组展示全部 AI 模型接口，由 `docusaurus-plugin-openapi-docs` 从 `openapi/relay.json` 渲染生成。

- 聊天（Chat）
- 补全（Completions）
- 嵌入（Embeddings）
- 重排序（Rerank）
- 审查（Moderations）
- 音频（Audio）
- 实时语音（Realtime）
- 图像（Images）
- 视频（Videos）
- 模型列表（Models）
- 未实现（Unimplemented，占位接口）
