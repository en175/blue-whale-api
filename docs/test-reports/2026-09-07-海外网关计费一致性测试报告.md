## 1. 背景与目标

### 1.1 背景
海外网关（`https://api.yunjizi.cn`）作为 New API 部署的海外实例，向上游 Dreamina 国际版（`artsdance2-0-pro-intl-260701`）转发视频生成请求，并按自身计费规则向调用方扣 quota 点数。本次测试对照**Dreamina 官方刊例价表**验证网关扣费准确性。

### 1.2 测试目标
- **G1 静态定价**：网关 `/api/pricing` 的 model_ratio 与官方刊例价是否匹配
- **G2 动态扣费**：不同分辨率/场景（scene × resolution）下网关实扣 quota 是否精确符合刊例价
- **G3 模型能力覆盖**：网关挂的 seedance-2.0 实际支持哪些 (scene × resolution) 组合

### 1.3 测试结论（先行摘要）
**海外网关 seedance-2.0 计费与 Dreamina-Seedance-2.0 Standard 刊例价 100% 吻合。** 实测 4 个 (scene × resolution) 档位全部精确等于刊例价。覆盖范围受网关/上游模型能力限制：仅支持 720p / 1080p × T2V / V2V，480p 和 I2V（image_url 图生）不被支持。

## 4. 测试执行

### 4.1 探测阶段（只读，不烧钱）

**a) `/v1/models` 模型列表**

```
HTTP 200 → 共 1 个模型：seedance-2.0
```

**关键发现**：海外网关只挂了一个视频模型 `seedance-2.0`。图片表的 4 个型号（Mini/Fast/Standard/2.5/1.0 Pro）当前**仅 Standard 一档在线**。

**b) `/api/pricing` 静态定价**

```
model_name:   seedance-2.0
model_ratio:  3.5
model_price:  0
completion_ratio: 0
enable_groups: [vip1, default, svip, vip]
group_ratio:  {default: 1, vip: 0.89, vip1: 0.88}
```

**关键发现**：`/api/pricing` 表面只显示一行 `model_ratio=3.5`，但 3.5 × 2 = $7.0/M **精确等于**图片表 Standard·T2V·720p 刊例价。**单一静态值无法覆盖 4 档差异**，差异扣费必然来自 channel 侧动态映射（实测验证）。

**c) 提交探针**

```
最简提交 model=seedance-2.0 → HTTP 400 UNSUPPORTED_MODEL_CONFIGURATION
（连续 3 把 key 同样错误，诊断为网关渠道未激活）
```

### 4.2 阻塞与解决

| 阻塞 | 根因 | 解决 |
|------|------|------|
| UNSUPPORTED_MODEL_CONFIGURATION | 上游欠费 → 渠道未激活 | 上游补费后恢复 |
| 403 insufficient_user_quota | default 账户余额耗尽 | 用户充值后恢复 |
| group client0904 No available channel | 网关分组渠道挂载漂移 | 用户修复后恢复 |

> 阻塞排查过程涉及多把密钥反查与跨网关对比，详见 `volcano_billing_test_overseas/probe.py` 与本次会话日志。

### 4.3 实测执行

按 (scene × resolution) 6 档设计用例，实际执行：

- 提交用 `POST /v1/video/generations`，body 含 `model`、`prompt`、`metadata.{resolution, duration, content}`
- V2V 用 `content[].type=video_url + role=reference_video`
- 提交即返 `task_id`，轮询 `GET /v1/video/generations/{task_id}` 至终态
- 从响应 `data.data.usage.total_tokens` 取透传 tokens，从 `data.quota` 取实扣 quota
- 计算 `quota/tokens = 实测倍率`，反推 `单价(USD/M) = 倍率 × 2`

### 5.1 实测数据汇总（4 档全部吻合）

| 场景 | 分辨率 | tokens | quota | **实测倍率** | **反推单价** | 实扣(USD) | 刊例价 | **结论** |

**4 / 4 全部精确吻合，零偏差。**

### 5.2 tokens 增长规律（实测）

| 维度对比 | tokens 比 | 说明 |
|---------|----------|------|
| T2V·1080p / T2V·720p | 245025 / 108872 ≈ 2.25x | 1080² / 720² = 2.25，**像素精准线性** |
| V2V·720p / T2V·720p | 216845 / 108872 ≈ 1.99x | 视频输入大致 2 倍 tokens |
| V2V·1080p / T2V·1080p | 488025 / 245025 ≈ 1.99x | 视频输入同样 ~2 倍 tokens |

### 5.3 上游链路（实测）

- 上游真实模型：`artsdance2-0-pro-intl-260701`（Dreamina 国际版，4 条统一）
- 网关渠道：`channel_id=9`
- 任务平台：`platform=59`（网关侧），`platform=54`（上游侧）
- 上游响应：5–10s 内可获 `usage.total_tokens`

## 6. 未验证档位及原因

### 6.1 I2V（图生视频，image_url 输入）

```
提交 HTTP 500: upstream_error: Internal server error
（连续 2 次，确认非偶发）
```

**根因**：海外网关 seedance-2.0 上游**只接受 video_url 输入**（即 V2V 视频续作），不接受 image_url（图生视频）。这是网关/上游模型能力限制，**不是计费问题**。

**与 V2V 的关系**：图片表把 I2V / V2V 合并为同价一档（$4.3/$4.7），已用 V2V 实测覆盖该档。I2V 在本网关下不被支持，无计费发生。

### 6.2 480p（任意场景）

```
提交 HTTP 400: 当前分辨率 480p 不支持
```

**根因**：网关/上游模型能力校验拒绝 480p 输入。图片表里 480p / 720p 同价，**网关不支持 480p = 不可能因 480p 计费**。

## 7. 关键发现

### 7.1 静态定价与实际扣费行为不一致（隐藏风险）

`/api/pricing` 静态仅显示 `model_ratio=3.5`（对应 $7/M），但实际网关按 4 个独立倍率扣费：

| 实际倍率 | 对应单价 | /api/pricing 是否可见 |
|---------|---------|---------------------|
| 3.5000 | $7.0/M | ✅ 可见（静态行）|
| 3.8500 | $7.7/M | ❌ 隐藏（channel 动态映射）|
| 2.1500 | $4.3/M | ❌ 隐藏 |
| 2.3500 | $4.7/M | ❌ 隐藏 |

**风险**：仅看 `/api/pricing` 的运营/财务会以为网关只有一档价 $7/M，对 1080p / I2V 的折扣空间误判。**计费核对必须按 (scene × resolution) 端到端验证，不能仅看静态定价。**

### 7.2 网关挂的 seedance-2.0 仅对应 Standard 一档

图片表 4 个型号（Mini/Fast/Standard/2.5/1.0 Pro）当前只有 Standard 1 个模型名在线。其他 3 个型号海外网关**尚未上线**，无法做跨型号一致性测试。

## 8. 结论与建议

### 8.1 结论

**海外网关 seedance-2.0 计费与图片表 Dreamina-Seedance-2.0 Standard 刊例价完全一致**，4 个实测档位（720p/1080p × T2V/V2V）倍率精确等于刊例价 ÷ 2，零偏差。

| 维度 | 结论 |
|------|------|
| 静态定价 | `model_ratio=3.5` 对应 Standard·T2V·720p=$7.0/M 吻合 |
| 动态扣费 | 4 档差异化倍率精确符合图片表 |
| 计费公式 | `quota = tokens × model_ratio`，`1 USD = 500,000 quota` 经验证成立 |
| 模型能力 | 仅支持 720p / 1080p × T2V / V2V，480p / image_url I2V 不支持 |

### 8.2 建议

1. **运营/财务侧**：核对账时不能只看 `/api/pricing`，必须按 (scene × resolution) 分别核对实扣倍率
2. **网关侧补全**：Mini / Fast / 2.5 / 1.0 Pro 4 个型号刊例价已确认但网关未上线，建议按需补挂渠道
3. **能力文档补充**：海外网关 seedance-2.0 不支持 480p、不支持 image_url（图生视频），接入方文档需明示
