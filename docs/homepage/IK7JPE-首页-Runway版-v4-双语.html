Quick Start

三步接入Three steps to integrate

01

提交任务Submit a task

向生成接口提交一个视频生成任务，返回任务 ID 后进入异步队列。示例中的接口地址为占位地址，模型编号固定为 seedance-2.0-whitelist。Submit a video generation task to the generations endpoint; it returns a task ID and enters the async queue. The endpoint address in the example is a placeholder; the model ID is always seedance-2.0-whitelist.

bash 
# 提交视频生成任务# Submit a video generation task
curl -X POST https://api.bluewhale.ai/v1/video/generations \
  -H "Authorization: Bearer sk-xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2.0-whitelist",
    "prompt": "一只蓝鲸在深海中缓慢游过A blue whale gliding slowly through the deep sea",
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "duration": 5
  }'
02

轮询状态Poll the status

视频生成为异步任务，不提供回调；提交后每 5–10 秒轮询一次任务状态，直至 succeeded 或 failed。任务状态仅四种：queued、processing、succeeded、failed。Generation is asynchronous with no callbacks; poll the task status every 5–10 seconds until succeeded or failed. There are only four states: queued, processing, succeeded, failed.

bash 
# 每 5–10 秒轮询一次任务状态# Poll the task status every 5–10 seconds
curl https://api.bluewhale.ai/v1/video/generations/task_9f3a2b7c \
  -H "Authorization: Bearer sk-xxx"

# → { "status": "processing" }
03

下载视频Download the video

任务状态为 succeeded 后，通过下载接口获取视频文件。Once the task is succeeded, fetch the video file via the download endpoint.

bash 
# 下载视频文件到本地# Download the video file locally
curl -L https://api.bluewhale.ai/v1/videos/task_9f3a2b7c/content \
  -H "Authorization: Bearer sk-xxx" \
  -o video

鉴权方式Authentication

所有接口统一通过请求头鉴权，将 sk-xxx 替换为你的 API Key。All endpoints authenticate via the request header — replace sk-xxx with your API key.

Authorization: Bearer sk-xxx

统一错误格式Unified error format

错误统一返回 {code, message, data} 结构；401 表示鉴权失败，429 表示触发限流。Errors share one {code, message, data} envelope; 401 means auth failure, 429 means rate-limited.

{"code": 401, "message": "unauthorized", "data": null}

限流说明Rate limits

接口存在限流保护，具体的配额与速率以实际环境为准。Endpoints are rate-limit protected; specific quotas and rates depend on the actual environment.
