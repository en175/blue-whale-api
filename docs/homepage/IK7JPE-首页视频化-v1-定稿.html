快速上手

3 行代码，从提示词到成片

1 提交任务
POST 
# 提交视频生成任务，返回 task_id
BASE="https://api.bluewhale.ai"
curl "$BASE/v1/video/generations" \
  -H "Authorization: Bearer sk-YOUR-KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2.0",
    "prompt": "蓝鲸跃出海面，慢镜头，电影质感",
    "size": "720p",
    "duration": 5
  }'
2 轮询状态
GET 
# 轮询任务状态
# queued / processing /
# succeeded / failed
BASE="https://api.bluewhale.ai"
curl "$BASE/v1/video/generations/{task_id}" \
  -H "Authorization: Bearer sk-YOUR-KEY"

# 响应示例
{ "code": "success",
  "data": {
    "task_id": "task_xxxx",
    "status": "succeeded"
  }
}
3 下载视频
GET 
# 任务完成后下载视频
BASE="https://api.bluewhale.ai"
curl "$BASE/v1/videos/{task_id}/content" \
  -H "Authorization: Bearer sk-YOUR-KEY" \
  -o result.mp4

# 返回 video/mp4 二进制流
# 需任务状态为 succeeded，
# 否则返回错误提示

base_url 为占位示意，正式域名以官方公告为准。完整字段说明见文档站。
