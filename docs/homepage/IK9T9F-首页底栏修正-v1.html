Quick Start

三步接入

01

提交任务

向生成接口提交一个视频生成任务，返回任务 ID 后进入异步队列。示例中的接口地址为占位地址，模型编号任选模型列表之一（示例用 doubao-seedance-2-0-260128）。

bash 
# 提交视频生成任务
curl -X POST https://api.bluewhale.ai/v1/video/generations \
  -H "Authorization: Bearer sk-xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-0-260128",
    "prompt": "一只蓝鲸在深海中缓慢游过",
    "seconds": "5",
    "metadata": {
      "resolution": "720p",
      "ratio": "16:9",
      "generate_audio": true
    }
  }'
02

轮询状态

视频生成为异步任务，不提供回调；提交后每 5–10 秒轮询一次任务状态，直至 succeeded 或 failed。任务状态仅四种：queued、processing、succeeded、failed。

bash 
# 每 5–10 秒轮询一次任务状态
curl https://api.bluewhale.ai/v1/video/generations/task_9f3a2b7c \
  -H "Authorization: Bearer sk-xxx"

# → { "status": "processing" }
03

下载视频

任务状态为 succeeded 后，通过下载接口获取视频文件。

bash 
# 下载视频文件到本地
curl -L https://api.bluewhale.ai/v1/videos/task_9f3a2b7c/content \
  -H "Authorization: Bearer sk-xxx" \
  -o video

Developers

为开发者设计

鉴权方式

所有接口统一通过请求头鉴权，将 sk-xxx 替换为你的 API Key。

Authorization: Bearer sk-xxx

统一错误格式

错误统一返回 {code, message, data} 结构；401 表示鉴权失败，429 表示触发限流。

{"code": 401, "message": "unauthorized", "data": null}

限流说明

接口存在限流保护，具体的配额与速率以实际环境为准。

HTTP/1.1 429 Too Many Requests
